# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина, разработанную с использованием CSS-фреймворка Bootstrap 5.

## Используемый фреймворк

Bootstrap 5.3.3.

## Способ подключения

Bootstrap подключён через CDN (jsDelivr).

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница товара;
- `order.html` — форма заявки;
- `css/custom.css` — дополнительные стили проекта;
- `images/` — папка для изображений;
- `README.md` — описание проекта.

## Реализованные компоненты Bootstrap

- `navbar` — навигационная панель;
- `card` — карточки товаров;
- `btn` — кнопки;
- `badge` — значки (Новинка, Хит, Скидка);
- `alert` — информационные сообщения;
- `modal` — модальное окно быстрой заявки;
- `breadcrumb` — хлебные крошки;
- `table` — таблица характеристик;
- `form-control`, `form-select`, `input-group`, `form-check` — элементы формы;
- `accordion` — блок «Частые вопросы».
